# Aventura Anabellei

Un joc de platforme in patru niveluri, gandit de Anabelle.

1. **Supermarketul** - strange banuti, sari peste tepi si monstruleti, ajungi la croitorie.
2. **Galeria comerciala** - drumul catre salon, pentru par si machiaj.
3. **Padurea vrajitorului** - vrajitorul o face zana si ii da aripi.
4. **Sus, prin nori** - zboara pana la castelul printesei.

Ciuperca magica o face SUPER ANABELLE: arunca bile de foc si incaseaza o lovitura
in locul unei inimi. Sariturile sunt duble.

Comenzi: sageti / A / D ca sa mergi, sus / W / Spatiu ca sa sari (de doua ori
pentru saritura dubla), X sau F pentru bile de foc. Pe telefon exista butoane pe
ecran; se joaca cel mai bine cu telefonul culcat.

Tot jocul este un singur fisier HTML, fara nicio dependinta.
Serverul (`server.js`) doar il serveste.

    npm start   # http://localhost:3000
